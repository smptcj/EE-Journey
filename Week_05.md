# Week 05 - Completing the Arduino Projects Book

**Date:** 1 September 2026

## Overview

This week focused on completing the guided projects in the Arduino Projects Book included with the Arduino Uno R3 Starter Kit. The projects provided a structured introduction to combining programming with physical electronic components, progressing from basic digital I/O to sensors, displays, sound, motors, and interactive systems.

## Practical Work

Worked through the later projects in the Arduino Projects Book, applying concepts introduced throughout the earlier experiments.

The projects explored combinations of:

* Digital inputs and outputs
* Analog inputs
* Sensors
* LEDs and RGB LEDs
* Potentiometers
* Buttons
* Piezoelectric components
* LCD displays
* Servo motors
* DC motors
* Transistors and motor drivers
* Capacitors and diodes

The progression helped demonstrate how individual components can be combined into larger interactive systems.

## Concepts Consolidated

* Digital I/O
* Analog input
* PWM
* Sensor interfacing
* Serial communication
* Timing and control
* Basic actuator control
* Motor control
* Transistor switching
* Breadboard prototyping
* Embedded C++ programming

## Key Findings

* Arduino projects become substantially more complex when multiple inputs and outputs are combined into one system.
* Many apparently different projects rely on the same fundamental pattern: sensing an input, processing the information in software, and producing an output.
* Hardware behaviour cannot always be solved through software alone; circuit design and component selection directly affect how a system operates.
* Using libraries can simplify interaction with more complex hardware, but understanding the underlying electrical behaviour remains important.
* Following a provided circuit is useful for learning the fundamentals, but designing and modifying circuits independently requires a deeper understanding of the components involved.

## Engineering Observations

The guided projects exposed several recurring engineering principles:

**Input → Processing → Output**

Sensors and user controls provide information to the microcontroller, the program processes that information, and an actuator or display produces a response.

The projects also demonstrated that a working system is the result of both hardware and software interacting correctly rather than either being treated independently.

## Reflection

Completing the Arduino Projects Book has provided a practical foundation for working with microcontrollers and basic electronic components. The projects were useful for learning the Arduino environment, but they were largely structured around following predetermined designs.

The next stage should therefore move beyond reproducing existing examples. I now want to begin designing and modifying circuits independently, using the circuit theory studied through MIT OpenCourseWare to explain design decisions and analyse the behaviour of the systems I build.

This marks the transition from learning how to use Arduino to using Arduino as a tool for learning Electrical Engineering.
